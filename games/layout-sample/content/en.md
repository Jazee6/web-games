Layout Sample is a placeholder draft game with no gameplay; it gives the site a second game so that category pages, related games and guide links can be built and checked before real games ship.

## How to Play

There is nothing to play. Open the page and check the layout.

## Controls

- **Touch:** scroll the page.
- **Keyboard and mouse:** scroll the page, or use Tab to move between links.

## Tips

Compare this page with Contract Test to see the related games and guide sections.

## FAQ

### Will Layout Sample appear on the live site?

No. It is a draft, so it only appears on preview and local builds.
